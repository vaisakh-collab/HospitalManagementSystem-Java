# Class Design

## HospitalManagementSystem

### Attributes

- patients : List<Patient>
- doctors : List<Doctor>
- appointments : List<Appointment>
- consultations : List<Consultation>
- bills : List<Billing>
- prescriptions : List<Prescription>

### Methods

- addPatient(patient : Patient) : boolean
- addDoctor(doctor : Doctor) : boolean
- bookAppointment(appointment : Appointment) : boolean
- cancelAppointment(appointmentId : int) : boolean
- createConsultation(consultation : Consultation) : boolean
- createPrescription(prescription : Prescription) : boolean
- generateBill(bill : Billing) : boolean
- findPatient(patientId : int) : Patient
- findDoctor(doctorId : int) : Doctor

## Patient

### Extends

- Person

### Additional Attributes

- patientId : int

> **Note:** `patientId` is generated by the database using `AUTO_INCREMENT`.

### Additional Methods

- getPatientId() : int
- setPatientId(patientId : int) : void
- viewMedicalHistory() : List<Consultation>
  - Returns the patient's medical history as a list of consultations.
- viewAppointments() : List<Appointment>
  - Returns the patient's appointments as a list of appointments.
- viewPrescriptions() : List<Prescription>
  - Returns the patient's prescriptions as a list of prescriptions.

> **Note:** Patient-related data is retrieved from the database through the DAO layer.

---

## Doctor

### Extends

- Person

### Additional Attributes

- doctorId : int
- specialization : String

> **Note:** `doctorId` is generated by the database using `AUTO_INCREMENT`.

### Additional Methods

- getDoctorId() : int
- setDoctorId(doctorId : int) : void
- getSpecialization() : String
- setSpecialization(specialization : String) : void
- viewAppointments() : List<Appointment>
  - Returns the doctor's appointments as a list of appointments.
- isAvailable(requestedDate : LocalDate, requestedTime : LocalTime) : boolean
  - Checks the doctor's appointments assuming each appointment is 20 minutes long, and returns `true` if there is no overlap.

> **Note:** Appointment data is retrieved from the database through the DAO layer.
